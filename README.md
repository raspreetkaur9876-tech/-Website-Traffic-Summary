# Website Traffic Summary

## Project Overview
This project analyzes website traffic using Microsoft Excel.

## Objectives
- Analyze website visits by traffic source.
- Identify daily website traffic trends.
- Compare visits by device type.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- GitHub

## Dataset Columns
- Date
- Source
- Device
- Visits

## Key Insights
- Google generated the highest traffic with 1,400 visits.
- Mobile devices generated 1,600 visits.
- 5 November recorded the highest daily traffic with 730 visits.
- Total website visits were 3,120.

## Conclusion
This project demonstrates practical Excel data analysis, Pivot Tables, charts, and dashboard creation.
